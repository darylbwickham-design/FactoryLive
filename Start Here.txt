Factory Live for Satisfactory

1. In Satisfactory Mod Manager, select your Windows Steam install and profile.
   Install FactoryLive Stream Integrations and its Satisfactory Mod Loader dependency.
   Release 0.9.0-chaos.8 targets game builds 517554 and 520140.
2. Launch the game and load your save as host. The included bridge starts and
   arms when the world is ready. Close any older standalone bridge first.
3. In Lumia Stream, install Satisfactory Stream Integration from the Market.
   Add a Factory Live action to a chat command or channel-point reward.
   Disarm Bridge pauses viewer effects and clears the queue.
4. For Streamer.bot, follow MOB-ENDPOINTS.md in this source release. Set Mob to
   the creature you want and Quantity to the number to spawn. Wildlife has its
   own named endpoints. Mob Chaos only spawns hostile creatures.

Setup guides: https://lumi-con.com/factory-live/chaos/
