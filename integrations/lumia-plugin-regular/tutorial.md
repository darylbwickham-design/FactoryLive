# Satisfactory Stream Integration

1. Install [Factory Live in Satisfactory Mod Manager](https://ficsit.app/mod/FactoryLive). Choose version **0.9.0-chaos.6** under **Change version**.
2. Start Satisfactory and load a save as host. The mod starts and arms its bridge.
3. In Lumia Stream 9.4, open **Settings → Plugins**. Install and enable **Satisfactory Stream Integration**.
4. Choose **Install** when Lumia offers the bundled commands. Use **Chat Commands** for `!chaos` and `!nukem`. For rewards, choose **Use file target (Twitch Points Commands)**. Skip any you already have.
5. Open **Commands → Twitch Points**. Use **Sync with Twitch** to create or link the rewards you want. Review their prices before enabling them.

Only the streamer and moderators can run the two bundled chat commands. You can change a reward’s cost or cooldown in Lumia.

## Add a different effect

Edit a command or reward, open **Actions**, and pick **Satisfactory Stream Integration**. For **Spawn Hog**, choose a tier and quantity. Leave the multiplier at 1 to use that quantity.

Keep **Disarm Bridge** on a private action to clear pending effects. Use **Check Bridge** to see whether the game is ready.
